Source copies of the sounds built into the game (you don't need these to play):

  kill-1.mp3, kill-2.mp3, kill-3.mp3   knockout sounds, one picked at random per hit
  directors-room.mp3                   plays when you enter Adhiraj's office
  caught.mp3                           plays when police or security catch you
